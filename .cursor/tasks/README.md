# Tasks

One file per task in this folder. Agents: scan `*.md` here (except this README) for project direction.

## Frontmatter

```yaml
---
title: Short task name
status: upcoming | backlog | done
---
```

Optional body: a few lines of context, not a full spec.

## Status

| status | meaning |
|--------|---------|
| `upcoming` | next to work on |
| `backlog` | idea for later |
| `done` | shipped or no longer active |

## Add a task

Create `my-task-slug.md` with frontmatter and a brief description.
